# Attribution notes

The assembled notice, with the copyright line of every project below, is the [`NOTICE`](../NOTICE) file at the
root of the repository; licence texts are in [`LICENSES/`](../LICENSES).

Code, rules and ideas Dualyrics took from other open-source projects, with their licences and the files of
Dualyrics they went into. Only MIT, BSD and Apache-2.0 sources are ported; projects under the GPL or without a
licence are used for ideas only and are not listed as code sources. When a `NOTICE` file is assembled, copy the
exact copyright line from each project's `LICENSE` file; for Apache-2.0 projects also carry over any `NOTICE`
file of the upstream project.
